# Designer Guide

Im gonna use this file to write how to edit or make changes to the designs as a designer so if you want to edit the code you can.



### GITHUB

If you want to edit things please download github desktop and ill write how to do it here:

1. Download github desktop and vscode if you havent got it
2. clone repo by url in the desktop app (repository->add->clone url) paste the url for this page

### important! never make edits on the main branch EVER 
> make sure ur github desktop app says current branch 'name of branch' and only merge w dev or dont merge at all and ill do it

3. create a new branch called name_design_channges or something similar that tells what your doing
4. open the repo in vscode
5. make sure the folder is trusted, there should be a thingy on the top that says manage, or:
    1. Open the Command Palette (Ctrl+Shift+P on Windows/Linux or Cmd+Shift+P on Mac).
    2. Type and select 'Workspaces: Manage Workspace Trust'
    3. click trust
5. open the config.css file and make changes
6. you can preview things by opening index.html and clicking the web icon on the top right and reloading it
7. when done, on the github desktop app name your edits, click commit to main, then push to origin, then make a PR, if u dont know how to make a PR just message that ur branch has edits u wanna apply and ill do it


For colours and styles there is a main config.css file that has all of the variables that you would want to edit for the design.
